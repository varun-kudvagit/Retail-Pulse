
Retail-Pulse is a customer segmentation and product recommendation system designed to analyze consumer behavior, segment customers, and provide personalized product recommendations. The system utilizes KMeans clustering for customer segmentation, cosine similarity for recommending products, and TextBlob for generating synthetic reviews with sentiment analysis.

📌 Features:

Customer Segmentation: Segments customers into different groups based on their annual income and spending score using KMeans clustering.

Product Recommendation: Recommends products to customers based on the similarity with other customers' ratings using cosine similarity.

Synthetic Product Reviews: Generates synthetic reviews based on customer ratings and performs sentiment analysis using TextBlob.

Visualization: Visualizes customer segments and relationships between age and income.

🛠️ Tech Stack

Pandas: Data manipulation and analysis

NumPy: Numerical operations

Matplotlib: Data visualization

Scikit-learn: Machine learning for KMeans clustering and cosine similarity

TextBlob: Sentiment analysis for review generation
